5 텔레그램 발송

이 강의의 가장 중요한 한 가지

텔레그램 봇은 @BotFather에서 이 뉴스 전용으로 새로 만드세요. 토큰을 다른 곳과 공유하면 명령 수신이 충돌합니다.

✕ 쓰던 봇 토큰 공유
→ 봇당 명령 수신은 1곳만 허용 → 충돌(409). 명령봇이 먹통.
✓ 전용 봇 토큰 발급
/newbot 으로 새 봇 → 토큰·chat id 를 .env 에. 깔끔하게 작동.
Claude Code — 프롬프트

8 1회만 설정

GitHub에 열쇠 넣기

  • 1
    Settings → Secrets and variables → Actions — NAVER·TELEGRAM 키 4개를 등록(로그에 안 뜸)
  • 2
    Settings → Actions → General — Workflow permissions를 “Read and write”로 (결과 커밋용)
  • 3
    Actions 탭 → Run workflow — 지금 바로 1회 테스트. 텔레그램이 오면 성공
